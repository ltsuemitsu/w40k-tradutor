# Glossaries (Rogue Trader)

These files seed and support the **Warhammer 40,000: Rogue Trader** EN→PT-BR
glossary used by the translator.

| File | Role |
|---|---|
| `wiki_terms.json` | Offline wiki-style term list (~2.6k+), categories for preserve logic |
| `glossary_seed.json` | Small starter glossary (core lore preferences) |

The live community glossary at the repo root is **`../../glossary.json`**.

## Other games (Dark Heresy, etc.)

Do **not** assume this data is correct for another title.

- Build a new glossary, or fork and heavily edit this one.
- Use `wiki_sync.py`, the GUI glossary tools, and human review.
- Re-run preserve category choices; RT mechanics ≠ other Owlcat/40k CRPGs 1:1.

Game localization JSON must never be committed here.
